FREQUENTLY ASKED

What counts as a "node"?

A node is one monitored cell, machine, or fixed asset — not a user seat. A single line with 6 monitored stations counts as 6 nodes regardless of how many people log in.

Do we need new sensors?

Most sites start with existing PLC tags and a light sensor add-on. A site walk during onboarding determines exactly what, if anything, needs to be added.

Can we run this on-prem?

Yes, on Enterprise. Perception inference already runs at the edge on every plan — on-prem adds a fully local control plane for sites with strict data residency needs.

How long is a typical contract?

Annual terms are standard. Pilots are scoped per-cell over 8–12 weeks before a site-wide rollout — talk to sales for a scoped pilot quote.
